게임의 중국어 간체 언어 슬롯에 한국어를 적용합니다. 패치 설치 후 언어 설정에서 **한국어**를 선택하면 됩니다. 영어도 계속 선택할 수 있습니다.

여러 패치 버전으로 사건 진행과 양쪽 엔딩을 확인하고, 플레이 중 제보된 문제를 수정했습니다. **최종 rc3 단일 버전으로 처음부터 끝까지 다시 완주한 테스트는 아닙니다.** 검수 범위와 알려진 한계를 아래에 안내합니다.

## 설치 방법

1. 게임을 종료합니다.
2. 기존 한글패치가 설치돼 있다면 기존 `KoreanPatch/restore.cmd`를 실행해 원본을 복구합니다. 복원이 완료된 뒤 기존 `KoreanPatch` 폴더를 보관하거나 지웁니다. **복원 전에 `backup` 폴더를 지우지 마세요.**
3. [다운로드 페이지](https://github.com/yoodong724/TheRatline-ko/releases/tag/ratline-ko-23882898-rc3)의 **Assets**에서 `ratline-ko-23882898-rc3.zip`을 받습니다.
4. Steam 라이브러리에서 게임을 우클릭하고 **관리 → 로컬 파일 탐색**으로 게임 폴더를 엽니다.
5. ZIP 안의 `KoreanPatch` 폴더를 `Ratlines.exe`가 있는 폴더에 넣습니다.
   - `TheRatline/KoreanPatch/install.cmd`가 되는 구조입니다.
6. `KoreanPatch/install.cmd`를 실행합니다. 원본 파일 확인과 백업 후 패치를 적용합니다. 별도 Python 설치는 필요하지 않으며, 디스크 여유 공간은 약 **3GB**가 필요합니다.
7. 게임을 실행하고 설정의 언어에서 **한국어**를 선택합니다.

**GitHub의 `Source code (zip)`과 `Source code (tar.gz)`는 설치용 패치가 아닙니다.** 위 파일명을 가진 ZIP을 받아 주세요. 함께 첨부한 `.sha256` 파일은 다운로드 파일의 SHA-256 확인용입니다.

## 패치 업데이트·제거

게임을 종료한 뒤 `KoreanPatch/restore.cmd`를 실행하면 원본으로 복구됩니다. 복구 결과를 확인한 뒤 백업만 자동 삭제하며, `KoreanPatch` 폴더는 남습니다.

새 패치는 기존 패치를 복원한 다음 설치합니다. **rc3에는 이전 수정이 모두 포함되므로 rc1·rc2를 먼저 설치할 필요가 없습니다.** 새 `KoreanPatch`를 기존 폴더 위에 덮어썼다면 `restore.cmd`를 먼저 실행한 뒤 `install.cmd`를 실행하세요.

설치기가 다른 빌드나 원본 파일 불일치를 알리면 적용하지 않습니다. 백업이 없거나 원본 복구가 되지 않으면 Steam의 **게임 파일 무결성 확인**을 이용하세요. 설치·복구 도구는 개인 세이브와 게임 설정 레지스트리를 수정하지 않습니다.

## 최신 수정

- 와인 축제 포스터의 이름 15개를 해당 문양 중앙에 맞춰 대응 관계가 분명하게 보이도록 수정했습니다.
- 객실 사진 301·302에서 글자 배경 처리로 지워진 곰 인형·상자의 윤곽선을 복원했습니다.
- Steam이 정상 연결된 상태에서 타이틀 화면에 실행 안내가 계속 표시되던 문제를 수정했습니다.

자세한 버전별 수정 내역은 [CHANGELOG.md](CHANGELOG.md)를 참고하세요.

## 검수 범위·알려진 한계

- 사건 1–9 진행, 양쪽 엔딩, 재시작·언어 유지 등을 이전 검수 빌드에서 확인했고, 이후 변경 범위는 별도로 검사했습니다. 최종판 전체 완주를 다시 했다는 뜻은 아닙니다.
- 새 증거 알림 본문의 앞부분이 일시적으로 가려질 수 있습니다. 증거 지급과 진행에는 영향이 없습니다.
- 후일담 정답 직후 창이 닫히기 전에 선택 문구가 초기 상태로 잠깐 보일 수 있습니다.
- 후일담 완료 후 하루를 마치기 전에 게임을 종료하면 후일담을 다시 입력해야 할 수 있습니다.
- 일부 긴 위치명의 괄호 속 원어 표기가 검색 결과에서 잘릴 수 있습니다.
- 실제 키보드 한글 입력기 조합 입력 전수, 960×720 해상도, Steam Cloud 동기화는 확인 범위에 포함되지 않습니다.
- Windows판만 제공합니다. Steam Deck·Linux·macOS용 패치는 제공하거나 시험하지 않았습니다.

## 문제 제보

[Issues](https://github.com/yoodong724/TheRatline-ko/issues)에 패치 버전, 장/장면, 화면 캡처, 언어 설정, 재현 순서를 알려 주세요. 설치·복구 문제는 `install.cmd` 또는 `restore.cmd`의 출력도 함께 남겨 주세요.

## 저장소 소스 안내

게임 내용과 스포일러의 불필요한 노출을 줄이기 위해 **번역 본문·용어/정답 자료·수정 이미지·영상·빌드 입력·내부 검수 기록은 저장소에서 제외**했습니다. 설치기와 차분 생성·적용, 패키지 조립에 필요한 최소 소스만 보관합니다. 코드에 게임 문안이 직접 들어 있는 제작 스크립트와 기존 내부 작업 이력도 공개하지 않습니다.

**이 저장소의 소스만으로는 한글패치를 재현할 수 없습니다. 원본 게임을 추가로 갖고 있어도, 공개하지 않는 번역·자산·빌드 입력 없이는 완성된 패치를 재현할 수 없습니다.**

패치를 사용할 때는 Releases의 설치용 ZIP을 받으세요. 공개한 도구의 범위와 추가 입력은 [제작 도구 안내](docs/BUILDING.md)에 정리했습니다.

## 고지

The Ratline의 저작권은 원 개발사·배급사에 있습니다. 이 패치는 비공식 무료 팬 번역입니다. 원본 게임 전체를 배포하지 않으며, 정품 원본 파일에 차분과 한국어 제작물을 적용합니다. 사용한 폰트·설치기 실행 환경·제3자 구성 요소의 라이선스는 설치용 ZIP의 `KoreanPatch/LICENSES`와 `KoreanPatch/bin/python`에 포함돼 있습니다.
